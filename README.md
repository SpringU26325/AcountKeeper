# AccountKeeper 本地记账软件

**中文摘要：** AccountKeeper 是一款轻量、开源的本地记账软件，支持日常收支记录、账单导入、统计图表和数据备份。v0.1.9 新增后台自动检查更新，并加强更新过程中的数据保护，让升级更省心。

**English summary:** AccountKeeper is a lightweight, open-source desktop app for personal bookkeeping, with local data storage, bill imports, charts, and backups. Version 0.1.9 introduces automatic update checks and stronger safeguards for a more reliable upgrade experience.

🎉 我的第一个独立使用 vibe-coding 开发的记账软件！

## 🆕 v0.1.9 更新

本次更新聚焦「自动更新」与「数据安全」。

- **后台检查更新**：启动后自动在后台检查新版本，无需反复前往网页查看和手动下载。
- **升级由你决定**：发现新版后，可选择立即下载或暂不更新；下载完成后，由你确认重启安装。
- **更新包防篡改**：安装前检查更新包的来源和完整性，拒绝来源不可信或下载不完整的文件。
- **失败恢复与回退**：更新前自动备份账本和偏好，新版本启动失败时进入恢复流程，保护原有数据。
- **更新更稳健**：加强网络超时、程序占用和更新中断的处理，减少更新卡住、反复恢复或无法启动的问题。
- **桌面更整洁**：更新状态和日志统一保存在本地数据目录，普通启动不会在 exe 旁生成这些文件。

完整发布说明见 [v0.1.9 Release Note](docs/release-v0.1.9.md)。

## ✨ 功能特性

- **本地存储**：账本和偏好保存在你电脑的用户数据目录中，与程序文件分开存放，更新程序无需搬动账本。
- **自动检查更新**：后台发现新版本，支持软件内下载和确认重启安装。
- **更新数据保护**：升级前自动备份，启动异常时恢复或回退；更新完成后继续使用原有账本。
- **数据备份**：一键把账本与偏好打包为 zip，随时手动存档。
- **导入外部账单**：支持 CSV 与 XLSX，预览确认后写入，支持批次撤销。
- **直观的记账体验**：【支出 / 收入】切换按钮统一添加到添加区与编辑窗，用户始终输入正数，系统自动处理正负号。
- **多标签系统**：一条记录可以打 0 到多个标签，标签以 chips 形式直观展示，支持点选、删除、多选。标签池统一管理，不再区分收支方向。
- **日期与月份选择器**：日期字段点击 ▼ 弹出日历；统计 / 导出 / 图表三处的月份字段点击 ▼ 弹出月历，不需要手动敲 `YYYY-MM-DD` 或 `YYYY-MM`。
- **完整的增删改查**：支持添加、双击编辑、删除记录，以及实时搜索与筛选。
- **可视化统计**：按月统计收入与支出，并生成可视化柱状图，按标签聚合对比；多标签记录会分别计入每个标签，图内附有诚实的口径说明。
- **智能导出**：支持导出账单为 CSV 文件，**自动记住上次保存路径**。
- **响应式布局**：支持调整窗口大小，最小尺寸为 820×560；工具栏按钮按可用空间等比例分配。
- **趣味体验**：动态蜗牛动画与随机消息气泡（防伪标识）；长消息可在气泡内滚动阅读。
- **快捷入口**：一键打开数据目录，方便备份与查看。

## 📦 如何下载使用

首次使用，请前往 [GitHub 发布页](https://github.com/SpringU26325/AccountKeeper/releases)，下载 v0.1.9 的 Windows 可执行文件 `AccountKeeper.exe`，双击即可运行，无需安装 Python。

请保留文件名 `AccountKeeper.exe`，以便正常使用自动更新。

### 自动更新

软件启动后会在后台自动检查更新，无需再去网页手动下载后续版本。

发现新版时，你可以选择“立即下载”或“暂不更新”。下载完成并通过安全检查后，点击“立即重启”即可安装；也可以暂不重启，稍后再更新。下载时可查看进度，也可取消或让下载窗口退到后台。

没有网络时仍可正常记账，联网后可在软件内手动检查更新。源码运行暂不支持自动更新。

从尚不支持自动更新的旧版本升级到 v0.1.9，需要先手动下载本版本；此后即可使用软件内更新。

### 账本在哪里？更新会影响数据吗？

账本和偏好保存在 Windows 用户本地数据目录（AppData）中，通常位于：

`%LOCALAPPDATA%\SpringU26325\AccountKeeper`

可通过软件中的“打开数据目录”查看实际位置。

**账本与程序分开存放，更新失败或回退不会把账本当作安装文件删除。** 升级前，软件会自动备份账本和偏好；新版本只有在正常启动并完成必要检查后，才开放记账。如果更新未能完成，会进入恢复或回退流程；无法确认数据安全时，会暂停写入，避免在异常状态下继续修改账本。

自动更新不会上传你的账目。软件也保留一键备份功能，方便你另存一份账本。

请从项目发布页下载程序。若 Windows 显示安全提示，请先核对下载来源。

## 🐛 已知问题 (Alpha 版)

- **导入预览性能未达标**：大批量密集退款对翻页仍可能秒级卡顿；普通与混合数据翻页约 0.3–0.4 秒，密集退款对最慢约 5–7 秒。分页功能可用，性能验收未通过。
- **词表仍为公开初值**：退款、中性交易、支付宝状态等词条尚未逐行对账；支付成功等状态仍为待确认，不自动入账。
- **真实样例对账未完成**：导入结果需人工核对，不能替代真实账单逐行对账。
- **卸载**：暂未提供一键卸载功能。

## 🛠️ 技术栈

- SQLite (数据库)
- openpyxl (XLSX 读取)
- Matplotlib (图表)
- Pillow (图片处理)
- platformdirs (用户数据目录管理)
