# AccountKeeper 本地记账软件
*A lightweight, open-source personal accounting desktop application built with Python.*

🎉 我的第一个独立使用 vibe-coding 开发的记账软件！

## 🆕 v0.1.8 更新

本次更新聚焦「导入外部账单」与数据安全。

- **导入外部账单**：主页面「文件 → 导入外部账单」支持 CSV 与 XLSX，进入预览后确认才写入账本。
- **字段映射与偏好保存**：可手动指定列，保存映射偏好，下次自动匹配。
- **待确认与退款对**：识别规则跳过、待确认、疑似退款对；退款对按对确认，支持跨页。
- **完全重复检测**：默认跳过后续完全重复，可手动解除，解除后仍走语义判断。
- **分页预览**：每页 100 笔，页内自由滚动，固定分页条，支持上一页、下一页、跳页。
- **导入批次**：主页面「文件 → 导入批次」查看批次，支持整批撤销。
- **导入报告**：导入完成显示成功、失败、跳过与批次信息，可打开数据目录。
- **预览下拉入口修复**：展开时点击三角或文字区只收起一次，收起后再点才展开。
- **显式使用说明**：预览窗口提供浅蓝描边按钮，点击打开说明，不自动弹出。

完整发布说明见 [release-v0.1.8.md](docs/release-v0.1.8.md)。

## ✨ 功能特性

- **本地 SQLite 存储**：数据永远保存在你自己的电脑上，安全可靠。
- **数据备份**：一键把账本与偏好打包为 zip，随时手动存档。
- **导入外部账单**：支持 CSV 与 XLSX，预览确认后写入，支持批次撤销。
- **直观的记账体验**：【支出 / 收入】切换按钮统一添加到添加区与编辑窗，用户始终输入正数，系统自动处理正负号。
- **多标签系统**：一条记录可以打 0 到多个标签，标签以 chips 形式直观展示，支持点选、删除、多选。标签池统一管理，不再区分收支方向。
- **日期与月份选择器**：日期字段点击 ▼ 弹出日历；统计 / 导出 / 图表三处的月份字段点击 ▼ 弹出月历，不需要手动敲 `YYYY-MM-DD` 或 `YYYY-MM`。
- **完整的增删改查**：支持添加、双击编辑、删除记录，以及实时搜索与筛选。
- **可视化统计**：按月统计收入与支出，并生成可视化柱状图，按标签聚合对比；多标签记录会分别计入每个标签，图内附有诚实的口径说明。
- **智能导出**：支持导出账单为 CSV 文件，**自动记住上次保存路径**。
- **响应式布局**：支持调整窗口大小，最小尺寸为 820×560；工具栏按钮按可用空间等比例分配。
- **趣味体验**：动态蜗牛动画与随机消息气泡（防伪标识）；长消息可在气泡内滚动阅读。
- **快捷入口**：一键打开数据目录，方便备份与查看。

## 📦 如何下载使用

前往 [Releases](https://github.com/SpringU26325/AccountKeeper/releases) 页面，下载 v0.1.8 的 Windows 可执行文件 `AccountKeeper_v0.1.8-alpha.exe`，双击即可运行，无需安装 Python。

⚠️ **首次运行提示**：由于缺少数字签名，Windows 系统可能会弹出安全警告。请点击“更多信息” -> “仍要运行”即可正常使用。

记账数据和偏好保存在用户数据目录，具体位置可通过应用中的“打开数据目录”查看。更新前请关闭旧程序，并备份该目录；更新程序时保留原有数据目录。

## 🐛 已知问题 (Alpha 版)

- **导入预览性能未达标**：大批量密集退款对翻页仍可能秒级卡顿；普通与混合数据翻页约 0.3–0.4 秒，密集退款对最慢约 5–7 秒。分页功能可用，性能验收未通过。
- **词表仍为公开初值**：退款、中性交易、支付宝状态等词条尚未逐行对账；支付成功等状态仍为待确认，不自动入账。
- **真实样例对账未完成**：导入结果需人工核对，不能替代真实账单逐行对账。
- **卸载与更新**：目前暂未提供自动更新和卸载功能，需要手动下载覆盖。

## 🛠️ 技术栈

- Python 3.13
- CustomTkinter (GUI)
- SQLite (数据库)
- openpyxl (XLSX 读取)
- Matplotlib (图表)
- Pillow (图片处理)
- platformdirs (用户数据目录管理)

## 📝 运行源码

如果你有 Python 环境，也可以克隆本仓库，安装依赖后直接运行：

```
pip install -r requirements.txt
python account_keeper.py
```
