# AccountKeeper 本地记账软件

**中文摘要：** AccountKeeper 是一款轻量、开源的本地记账软件，支持日常收支记录、账单导入、可视化财务分析和数据备份。v1.0.0 正式版迎来了全新的数据分析面板与安全卸载机制，致力于为你提供最安心的本地记账体验。

**English summary:** AccountKeeper is a lightweight, open-source desktop app for personal bookkeeping, with local data storage, bill imports, interactive charts, and backups. Version 1.0.0 introduces a new data dashboard and secure uninstallation for a more reliable experience.

## 🆕 v1.0.0 重磅更新

本次更新是软件发布以来的最大规模升级，聚焦「视觉重构」、「数据分析」与「安全加固」。

- **📊 财务分析数据中心**：全新内嵌图表系统！提供标签横向条形图、每日趋势折线图（带日均线）以及近半年收支对比柱状图，并支持查看同环比涨跌与最大单笔支出。
- **🏷️ 标签智能记忆**：高频标签（如“餐饮”）按收支方向自动记忆，下次记账直接带出，省去重复输入的烦恼。
- **🗑️ 安全卸载功能**：新增软件内卸载入口。可选择保留或彻底删除数据，系统通过严格白名单校验防误删，且能实现安全的程序自清理。
- **🛡️ 底层史诗级重构与加固**：将千行巨型代码文件彻底拆分，软件运行更流畅；修复了导出 CSV 覆盖账本的高危漏洞；强化了更新模块的异常恢复与网络兼容能力。

## ✨ 功能特性

- **本地存储**：账本保存在本机 AppData 目录，与程序分离，拒绝云端上传，保护绝对隐私。
- **自动检查更新**：后台静默检查新版，软件内一键下载、确认重启安装。支持断点续传与防篡改校验。
- **可视化图表**：直观查看标签占比、每日花销走势以及近半年收支趋势，多标签记录分别计入，口径透明。
- **智能标签系统**：支持一条记录打多个标签，以 Chips 形式展示；自动记忆高频标签。
- **多维导入导出**：支持导入外部 CSV 与 XLSX 账单，自动解析并支持批次撤销；支持将账单导出为 CSV，并自动记忆导出路径。
- **一键备份**：随时将账本与偏好设置打包为 zip 压缩包。
- **响应式布局**：支持自由调整窗口大小，工具栏自适应等比例分配。
- **趣味体验**：动态蜗牛动画与随机消息气泡，让记账不再枯燥。

## 📦 如何下载使用

请前往发布页，下载最新的 `AccountKeeper.exe`，双击即可运行，无需安装 Python。请保留程序文件名 `AccountKeeper.exe`，以便正常使用自动更新功能。

### ⚠️ 升级须知（针对老用户）
如果您当前使用的是 **v0.1.9 或更早版本**，由于早期测试版底层的网络协议存在缺陷，可能无法通过软件内的“检查更新”直接升级。请您**手动下载 v1.0.0** 并覆盖原来的 exe 文件，您的账本数据不会丢失。从 v1.0.0 开始，后续版本均可通过软件内无缝自动更新。

### 账本在哪里？更新会影响数据吗？
账本和偏好保存在 Windows 用户本地数据目录（AppData）中，通常位于：`%LOCALAPPDATA%\SpringU26325\AccountKeeper`。可通过软件右上角的“应用 -> 打开数据目录”查看。

**账本与程序严格分开存放，更新失败或回退绝不会影响你的账本。** 自动更新也绝不会上传你的任何账目数据。

## 🐛 已知问题
- **早期版本更新限制**：v0.1.9 及更早版本的内部更新功能因受 Gitee API 风控影响，已失效。升级至 v1.0.0 需手动下载一次。
- 大批量密集退款对的导入预览仍可能出现秒级卡顿。
- 外部账单的识别结果仍需人工核对。
- 多实例并发修改同一笔记录时，可能存在后保存覆盖先保存的情况（后续版本引入乐观锁解决）。

## 🛠️ 技术栈

- Python 3.13
- CustomTkinter (GUI)
- SQLite (数据库)
- openpyxl (XLSX 读取)
- Matplotlib (图表)
- Pillow (图片处理)
- platformdirs (用户数据目录管理)
