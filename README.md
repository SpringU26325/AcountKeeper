# AccountKeeper 本地记账软件

🎉 我的第一个独立使用 vibe-coding 开发的记账软件！

## 🆕 v0.1.6 更新

本次更新主要提升弹窗响应速度、修复交互细节，并统一表格视觉。

- **标签弹窗提速**：打开标签多选列表不再每次重建窗口和候选行，改为复用窗口、按候选变化增量更新。主页面重复打开从约 200ms 降到约 80ms，编辑窗口降到约 76ms，肉眼几乎即时。
- **日期 / 月历提速**：复用 42 个日期格和 12 个月份格，翻页 / 翻年只更新变化内容；启动后在主线程分批隐藏预创建，首次打开不再闪烁。
- **弹窗关闭更干净**：修复关闭编辑、删除确认、标签弹窗时控制台偶发的 `bad window path name` 警告。窗口任务清理、grab 借还、父窗关闭保护统一走一套生命周期管理。
- **气泡点击穿透修复**：点击蜗牛气泡关闭时不再误触下方控件；按下保留、松开才真正关闭。
- **表格视觉统一**：备注列与其它列一样水平居中，表头与单元格对齐。
- **内部清理**：删除未绑定的死代码；收支总额与逐标签明细统一由公共聚合函数计算，避免统计口径漂移。

完整发布说明见 [release-v0.1.6.md](docs/release-v0.1.6.md)。

## ✨ 功能特性

- **本地 SQLite 存储**：数据永远保存在你自己的电脑上，安全可靠。
- **直观的记账体验**：新增【支出 / 收入】切换按钮，用户始终输入正数，系统自动处理正负号，记账更省心。
- **多标签系统**：一条记录可以打 0 到多个标签，标签以 chips 形式直观展示，支持点选、删除、多选。标签池统一管理，不再区分收支方向。
- **日期与月份选择器**：日期字段点击 ▼ 弹出日历；统计 / 导出 / 图表三处的月份字段点击 ▼ 弹出月历，不需要手动敲 `YYYY-MM-DD` 或 `YYYY-MM`。
- **完整的增删改查**：支持添加、双击编辑、删除记录，以及实时搜索与筛选。
- **可视化统计**：按月统计收入与支出，并生成可视化柱状图，按标签聚合对比；多标签记录会分别计入每个标签，图内附有诚实的口径说明。
- **智能导出**：支持导出账单为 CSV 文件，**自动记住上次保存路径**。
- **响应式布局**：支持调整窗口大小，最小尺寸为 820×560；工具栏按钮按可用空间等比例分配。
- **趣味体验**：动态蜗牛动画与随机消息气泡（防伪标识），右键蜗牛可触发传送彩蛋；长消息可在气泡内滚动阅读。
- **快捷入口**：一键打开数据目录，方便备份与查看。

## 📦 如何下载使用

前往 [Releases](https://github.com/SpringU26325/AccountKeeper/releases) 页面，下载 v0.1.6 的 Windows 可执行文件 `AccountKeeper_v0.1.6-alpha.exe`，双击即可运行，无需安装 Python。

⚠️ **首次运行提示**：由于缺少数字签名，Windows 系统可能会弹出安全警告。请点击“更多信息” -> “仍要运行”即可正常使用。

记账数据和偏好保存在用户数据目录，具体位置可通过应用中的“打开数据目录”查看。更新前请关闭旧程序，并备份该目录；更新程序时保留原有数据目录。

## 🐛 已知问题 (Alpha 版)

- **编辑弹窗高度上限**：标签数量极多（30+ 个）时编辑弹窗会触及屏幕高度上限，超出部分暂时无法滚动查看。
- **卸载与更新**：目前暂未提供自动更新和卸载功能，需要手动下载覆盖。

## 🛠️ 技术栈

- Python 3.13
- CustomTkinter (GUI)
- SQLite (数据库)
- Matplotlib (图表)
- Pillow (图片处理)
- platformdirs (用户数据目录管理)

## 📝 运行源码

如果你有 Python 环境，也可以克隆本仓库，安装依赖后直接运行：

```
pip install -r requirements.txt
python account_keeper.py
```
