# AccountKeeper 本地记账软件

🎉 我的第一个独立使用 vibe-coding 开发的记账软件！

## ✨ 功能特性
- **本地 SQLite 存储**：数据永远保存在你自己的电脑上，安全可靠。
- **直观的记账体验**：新增【支出 / 收入】切换按钮，用户始终输入正数，系统自动处理正负号，记账更省心。
- **多标签系统**：一条记录可以打 0 到多个标签，标签以 chips 形式直观展示，支持点选、删除、多选。类别池统一管理，不再区分收支方向。
- **日期与月份选择器**：日期字段点击 ▼ 弹出日历；统计 / 导出 / 图表三处的月份字段点击 ▼ 弹出月历，不再需要手动敲 `YYYY-MM-DD` 或 `YYYY-MM`。
- **完整的增删改查**：支持添加、双击编辑、删除记录，以及实时搜索与筛选。
- **可视化统计**：按月统计收入与支出，并生成可视化柱状图，按标签聚合对比；多标签记录会分别计入每个标签，图内附有诚实的口径说明。
- **智能导出**：支持导出账单为 CSV 文件，**自动记住上次保存路径**，下次导出省去重复选路径的烦恼。
- **响应式布局**：窗口任意大小下所有字段完整可见，工具栏按钮按可用空间等比例分配。
- **趣味体验**：动态蜗牛动画与随机消息气泡（防伪标识）。
- **快捷入口**：一键打开数据目录，方便备份与查看。

## 📦 如何下载使用
前往 [Releases](https://github.com/SpringU26325/AccountKeeper/releases) 页面，下载最新的 `AccountKeeper_v0.1.4-alpha.exe` 文件，双击即可运行。

⚠️ **首次运行提示**：由于缺少数字签名，Windows 系统可能会弹出安全警告。请点击“更多信息” -> “仍要运行”即可正常使用。

## 🐛 已知问题 (Alpha 版)
- **编辑弹窗高度上限**：标签数量极多（30+ 个）时编辑弹窗会触及屏幕高度上限，超出部分暂时无法滚动查看。
- **卸载与更新**：目前暂未提供自动更新和卸载功能，需要手动下载覆盖。
- **关闭弹窗时的控制台警告**：关闭部分弹窗时控制台可能打印 `bad window path name` 警告，不影响功能。
- **蜗牛图片 PNG 警告**：控制台偶尔打印 `libpng warning: iCCP` 警告，来自内置图片文件，不影响功能。

## 🛠️ 技术栈
- Python 3.13
- CustomTkinter (GUI)
- SQLite (数据库)
- Matplotlib (图表)
- Pillow (图片处理)
- platformdirs (用户数据目录管理)

## 📝 运行源码
如果你有 Python 环境，也可以克隆本仓库，安装依赖后直接运行：

```bash
pip install -r requirements.txt
python account_keeper.py
```
