# AccountKeeper v0.1.9

**中文摘要：** 本次更新带来后台自动检查更新、软件内下载与确认重启安装，并全面加强升级过程中的数据保护和异常恢复。账本继续保存在你的电脑上，升级更方便，也更安心。

**English summary:** AccountKeeper v0.1.9 adds automatic background update checks, in-app downloads, and user-confirmed installation. This release also strengthens backup, recovery, and update security while keeping your bookkeeping data stored locally.

## ✨ 新特性

### 软件内更新

- 启动后自动在后台检查新版本，无需反复打开发布网页。
- 发现新版后，可选择立即下载或暂不更新。
- 下载支持进度显示、取消和后台运行。
- 下载完成后，由你确认重启安装，不会擅自替换正在使用的程序。
- 支持在软件内手动检查更新。

### 升级前自动备份

- 安装更新前自动备份账本和偏好。
- 新版本需要正常启动并完成必要检查，之后才允许继续记账。
- 如果新版本启动失败，进入恢复或回退流程，保护升级前的账本。

## 🛠️ 优化与修复

### 更新更稳健

- 大幅加强更新模块的异常处理，减少更新卡住、反复恢复和无法启动的问题。
- 改善网络超时、下载中断和服务繁忙时的处理，避免长时间无响应。
- 加强程序文件被占用、更新组件被安全软件拦截时的恢复处理。
- 完善更新结束后的清理逻辑，减少临时文件残留影响正常启动的情况。
- 改善多个程序副本共用同一账本时的保护，避免更新与记账操作相互干扰。

### 底层安全加固

- 安装前核对更新包的来源与完整性，拒绝被篡改或不完整的文件。
- 更新组件与主程序一同接受安全检查。
- 无法确认更新状态时先暂停写入，防止异常操作继续影响账本。
- 完善回退后的处理，避免重复恢复覆盖后来新增的账目。

### 文件存放更清晰

- 更新状态和日志统一保存在 AppData 下，普通启动不再在桌面或 exe 旁生成这些文件。
- 不同安装位置的更新记录分别保存，互不覆盖。
- 更新安装包保留在程序所在磁盘，减少对系统盘空间的占用，并支持程序放在其他磁盘使用。

## 🔒 关于你的账本

**账本始终保存在本机的用户数据目录中，与程序文件分开存放。**

通常位置为：

`%LOCALAPPDATA%\SpringU26325\AccountKeeper`

也可以通过软件中的“打开数据目录”查看。

更新失败或回退不会将本地账本作为安装文件删除。升级前的自动备份、启动检查和异常恢复共同保护原有数据；更新状态不明确时，软件会优先保护账本，暂停写入，而不是继续冒险操作。

自动更新不会上传你的账目，一键备份功能也可继续使用。

## 📦 使用与升级

- 首次使用：从 [GitHub 发布页](https://github.com/SpringU26325/AccountKeeper/releases) 下载 `AccountKeeper.exe`，双击运行，无需安装 Python。
- 旧版本用户：关闭旧程序，手动下载并运行 v0.1.9，保留原有用户数据目录。
- 请保留程序文件名 `AccountKeeper.exe`，以便使用自动更新。
- 从 v0.1.9 开始，后续版本可通过软件内更新，无需反复前往网页下载。
- 自动更新适用于 Windows 打包版本，源码运行暂不支持。

## 📌 已知限制

- 大批量密集退款对的导入预览仍可能出现卡顿。
- 外部账单的识别结果仍需人工核对，不能替代逐笔对账。
- 暂未提供一键卸载功能。
