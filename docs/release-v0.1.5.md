# AccountKeeper v0.1.5

本次更新主要改善 Logo 与蜗牛的清晰度，并修复蜗牛在高 DPI、窗口缩放和气泡交互中的显示问题。

## 更新内容

### 全新清晰 Logo

重新制作 `logo.ico`，换上全新的 Logo，解决旧图标模糊的问题。

### 蜗牛素材更新

- 使用透明背景的深蓝加粗蜗牛，移除网格、文字等残留元素。
- 保留高分辨率源图，改善高 DPI 下触角、螺旋和轮廓的清晰度。

### 高 DPI 与窗口缩放修复

- 修复入场时跳位、缩放后回到旧位置的问题。
- 缩小窗口时，暂停的蜗牛会移回最近的可见路线位置，并避开标题。
- 活动气泡随窗口尺寸变化重新排版，重排不会重置自动关闭时间。

### 气泡排版与长文阅读改善

- 正确保留显式换行、首尾及连续空行，修复多行文字裁切。
- 气泡限制在窗口可见范围内，贴边时尾巴不再伸出画布。
- 长消息支持竖向滚动条和鼠标滚轮，保留全部正文。
- 每次滚动后重新计时3秒，普通消息仍在显示3秒后自动关闭。

### 动画启停与焦点处理改善

- 避免重复启动产生重复控件或多条动画链。
- 蜗牛或窗口销毁后清理定时任务和事件绑定。
- 根据实际焦点所在窗口判断暂停和恢复，避免主窗口内部切换输入控件时误暂停。
- 气泡显示期间，切回主窗口仍保持蜗牛暂停。

## 升级说明

关闭旧版程序后，下载并运行 `AccountKeeper_v0.1.5-alpha.exe`，无需安装 Python。

数据和偏好保存在用户数据目录，可通过“打开数据目录”查看；更新前请备份该目录，更新时保留原有数据。

## 已知问题

本项目仍处于 Alpha 阶段，以下问题尚待处理：

- 点击关闭气泡时，可能同时触发下方控件。
- 编辑弹窗标签数量极多时，超出高度的内容暂时无法滚动查看。
- 关闭部分弹窗时，控制台可能出现 `bad window path name` 警告。
- 暂未提供自动更新和卸载功能。
