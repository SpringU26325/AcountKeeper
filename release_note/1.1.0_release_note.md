# AccountKeeper v1.1.0 更新日志

## 预算管理

- 按自然月设置总预算和单个标签预算，查看已花金额、剩余额度、使用比例和逐笔明细。可切换月份或一键补齐上月额度，保留本月已设置的额度。
- 新增或编辑支出时可勾选「不计入预算」。预算页单独列出预算外支出，账本和财务分析仍将其计入实际支出。
- 预算窗打开期间，账目新增、编辑、删除、导入或撤销后，进度和已打开的明细同步刷新。
- 保存计入预算的本月支出后，档位上升时在记账区和蜗牛气泡提示。达到 80% 为「接近上限」，达到 100% 为「已用完」，超过 100% 为「超支」。
- 同一笔支出触发多项预算时合并提示。气泡可点击关闭，也会在约 5 秒后自动关闭。

## 记账与财务分析

- 「记一笔」采用双行录入和固定底栏。保存反馈与顶部预算气泡分开显示，金额框聚焦时显示蓝色圆角描边。
- 点击标签图的柱子或每日趋势中的日期，可查看构成金额的账目。
- 在主窗按 `Ctrl+F` 快速聚焦搜索框。

## 升级与备份

- v1.0.0 至 v1.0.2 可在软件内检查更新。v0.1.9 或更早版本请手动下载新版替换程序，保留文件名 `AccountKeeper.exe`。
- 旧账目升级后默认计入预算。手动 ZIP 备份随账本保存月度预算额度和预算外标记。
