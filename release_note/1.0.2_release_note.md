# AccountKeeper v1.0.2 更新日志

**主题：导入外部账单，体验全面重塑**

本次更新没有新增长尾功能，但把你最常用的「导入外部账单」从里到外翻新了一遍——图标统一、布局重构、高分屏适配、交互细节打磨。

## ✨ 更新内容

### 🖼️ 弹窗图标统一
修复了导入预览窗、导入流程窗口、帮助窗及多列选择窗显示默认蓝色系统图标的问题。现在所有弹窗都与你主程序的应用图标保持一致，窗口栏、任务栏不再「跳色」。

### 🎨 导入窗口布局重构
- **双栏设计**：左侧字段与提示集中展示，右侧明细区独立呈现，动线更清晰。
- **字段优先级前置**：日期、金额、原备注等关键字段排在最前，缺项提示集中在左栏一眼可见。
- **明细区收纳**：计数、搜索与筛选工具收进明细区顶部，分页条移到表格下方，操作不散落。

### 🧠 冲突组三态交互
未选时下拉可用、确认禁用；选后自动试算并展示核对内容，确认后才改变决定；已确认自动收起为摘要，保留修改与清除入口。决策状态一目了然，避免误操作。

### 📝 备注列前置
原备注列紧跟原始数据展示，关键信息无需横向滚动即可查看。

### 📐 高分屏与自适应
- 100% / 125% DPI 缩放下完成视觉验收，修复了 125% 档日期/金额表头相挤的问题。
- 修复了下拉框边框描边被裁切、圆角显示残缺的缺陷。
- 顶部计数格在窄窗下自动从 1×4 切换为 2×2，任何窗口尺寸下都保持可读。

## 🧰 内部质量
更新模块架构白皮书归档至 docs/，签名工具链、事务状态机、崩溃恢复、逃生口等机制有了完整文档依据；签名、客户端、helper 三层验收探针在本轮复验中全部通过，导入模块流程 49 项、预览 141 项断言通过。

## ⚠️ 升级须知
- **v1.0.0 / v1.0.1**：可直接在软件内通过「检查更新」平滑升级，账本数据与程序严格分离，更新绝不影响数据。
- **v0.1.9 或更早**：请手动下载 v1.0.2 覆盖原文件（账本数据绝对不会丢失）。
- 请保留程序文件名 AccountKeeper.exe，以便正常使用自动更新功能。
